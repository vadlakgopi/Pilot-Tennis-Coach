# Documentation

This folder contains all project documentation organized to mirror the codebase structure.

## Structure

```
Documentation/
├── apps/
│   ├── api/          # API documentation
│   ├── mobile/       # Mobile app documentation
│   └── web/          # Web app documentation
└── services/
    └── ml-pipeline/  # ML Pipeline documentation
        └── training/  # Training documentation
```

## Guidelines

- All `.md` files should be placed in the appropriate subfolder matching the code structure
- Keep documentation organized and up-to-date with code changes
- Use clear, descriptive filenames
- Include examples and code snippets where relevant
